# 오늘의 진짜 정보판

부산의 현재 기온을 실제 공개 데이터에서 조회하고,
데이터가 정상적으로 들어오지 않는 상황에서도 마지막 정상값을 유지할 수 있도록 만든
간단한 날씨 정보판입니다.

## 프로젝트 소개

이 웹사이트는 Open-Meteo의 공개 API를 이용해 부산의 현재 기온을 보여줍니다.

단순히 날씨를 표시하는 것에 그치지 않고 다음 정보를 함께 기록합니다.

- 현재 기온과 단위
- 데이터 측정 시각
- 데이터 조회 시각
- 시간대
- 데이터 출처

같은 날짜에 여러 번 조회하더라도 하나의 일별 기록만 유지하며,
다른 날짜의 실제 기록이 존재하면 전일과 비교할 수 있습니다.

## 데이터 장애 대응

외부 데이터 조회 과정에서 발생할 수 있는 상황을 테스트할 수 있도록 구성했습니다.

- Timeout
- 401/403 인증 오류
- 429 요청 제한
- Offline
- 응답 구조 변경

오류가 발생하면 마지막으로 정상적으로 저장된 값을 유지하고,
현재 데이터가 최신 상태가 아님을 표시합니다.

이후 `다시 시도`를 통해 정상 상태로 복구되는 흐름을 확인할 수 있습니다.

## 데이터 출처

- Open-Meteo
- 부산 좌표: 위도 35.1796, 경도 129.0756
- 시간대: Asia/Seoul
- API Key가 필요하지 않은 공개 API 사용
